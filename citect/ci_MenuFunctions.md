# Menu Functions        

Функції роботи з деревом меню.

Наведені нижче функції дозволяють отримувати доступ до вмісту бази конфігурації меню у вигляді дерева та змінювати це дерево під час виконання.

Зміни, внесені до дерева меню під час виконання, не зберігаються назад у базу конфігурації меню.

| Функція                 | Опис                                                         |
| ----------------------- | ------------------------------------------------------------ |
| MenuGetChild            | Повертає дескриптор дочірнього вузла із заданим ім’ям.       |
| MenuGetFirstChild       | Повертає дескриптор першого дочірнього вузла меню.           |
| MenuGetGenericNode      | Повертає дескриптор базового вузла дерева меню для універсальних сторінок. |
| MenuGetNextChild        | Повертає наступний вузол, який має того самого батьківського вузла. |
| MenuGetNodeByPath       | Повертає дескриптор меню, що відповідає вказаному елементу меню. |
| MenuGetPageNode         | Повертає дескриптор базового вузла дерева меню для вказаної сторінки. |
| MenuGetParent           | Повертає батьківський вузол елемента меню.                   |
| MenuGetPrevChild        | Повертає попередній вузол, який має того самого батьківського вузла. |
| MenuGetWindowNode       | Повертає дескриптор кореневого вузла для вказаного вікна.    |
| MenuNodeAddChild        | Динамічно додає новий елемент до меню під час виконання.     |
| MenuNodeGetCurr         | Повертає дескриптор вузла меню під час виклику пов’язаної з ним команди. |
| MenuNodeGetDepth        | Повертає рівень вкладеності вказаного вузла в ієрархії меню. |
| MenuNodeGetProperty     | Повертає значення властивості вказаного вузла меню.          |
| MenuNodeGetTargetPage   | Повертає цільову сторінку для вказаного вузла меню.          |
| MenuNodeHasCommand      | Перевіряє, чи пов’язана з вузлом меню коректна команда Cicode. |
| MenuNodeIsDisabled      | Перевіряє, чи вимкнений вузол меню, обчислюючи його вираз `DisabledWhen`. |
| MenuNodeGetExpanded     | Повертає стан розгортання вказаного вузла меню.              |
| MenuNodeIsHidden        | Перевіряє, чи прихований вузол меню, обчислюючи його вираз `HiddenWhen`. |
| MenuNodeRemove          | Видаляє вузол із дерева меню.                                |
| MenuNodeRunCommand      | Виконує команду, пов’язану з вузлом меню.                    |
| MenuNodeSetDisabledWhen | Задає вираз `DisabledWhen` для нового вузла.                 |
| MenuNodeSetExpanded     | Задає стан розгортання вказаного вузла меню.                 |
| MenuNodeSetHiddenWhen   | Задає вираз `HiddenWhen` для нового вузла.                   |
| MenuNodeSetProperty     | Задає значення властивості вказаного вузла меню.             |
| MenuReload              | Повторно завантажує базову конфігурацію меню зі скомпільованої бази даних. |
