# SA_Controls Library

Бібліотека `sa_controls` входить до системного проєкту `SA_Controls` і містить готові Genie для відображення табличних даних на сторінках Plant SCADA.

До складу бібліотеки входять:

| Genie           | Призначення                                                  |
| --------------- | ------------------------------------------------------------ |
| `alarmlist`     | Таблиця тривог із заголовком колонок                         |
| `alarmlist_v`   | Таблиця тривог без заголовка                                 |
| `genericlist`   | Універсальна таблиця користувацьких даних із заголовком      |
| `genericlist_v` | Універсальна таблиця користувацьких даних без заголовка      |
| `list_row_x<n>` | Допоміжний Genie для вибору рядків, контекстного меню та форматування |

## Alarm List Genie

Genie `alarmlist` призначений для відображення списку тривог у вигляді таблиці з заголовками колонок та горизонтальною і вертикальною прокруткою. За замовчуванням використовує дані, сформовані функцією `AlarmListCreate()`.

### Основні параметри

| Параметр                    | Призначення                                                 |
| --------------------------- | ----------------------------------------------------------- |
| `AN`                        | Унікальний ідентифікатор об'єкта. Заповнюється автоматично. |
| `OnRightClickFunction`      | Викликається при натисканні правої кнопки миші на списку.   |
| `OnColumnSelectedFunction`  | Викликається при виборі колонки.                            |
| `OnColumnReorderedFunction` | Викликається при зміні порядку колонок.                     |
| `OnColumnResizedFunction`   | Викликається при зміні ширини колонок.                      |

### Ініціалізація

На події відкриття сторінки необхідно створити список:

```cicode
_ArrayView_Initialize();

AlarmListCreate(
    DspGetAnFromName("alarmlist"),
    ...
);
```

На події закриття сторінки:

```cicode
AlarmListDestroy(
    DspGetAnFromName("alarmlist")
);
```

### Примітка

Саме через параметри `OnColumnReorderedFunction` та `OnColumnResizedFunction` реалізується підтримка зміни порядку колонок та їх ширини користувачем. Як приклад у документації наведена функція:

```cicode
ArrayView_SetFormat()
```

що вказує на використання механізму ArrayView для керування представленням таблиці.

## Alarm List Vertical Genie

Genie `alarmlist_v` є спрощеним варіантом `alarmlist`.

Відмінності:

- відсутній рядок заголовків;
- використовується тільки вертикальна прокрутка;
- решта механізмів роботи ідентичні `alarmlist`.

## Generic List Genie

Genie `genericlist` призначений для відображення довільних даних, які формуються користувацьким Cicode.

На відміну від Alarm List, джерело даних визначається самим розробником.

### Основні параметри

| Параметр                    | Призначення                         |
| --------------------------- | ----------------------------------- |
| `AN`                        | Унікальний ідентифікатор списку     |
| `GenericListFillFunction`   | Функція, яка заповнює список даними |
| `OnRightClickFunction`      | Обробник правої кнопки              |
| `OnColumnSelectedFunction`  | Обробник вибору колонки             |
| `OnColumnReorderedFunction` | Обробник зміни порядку колонок      |
| `OnColumnResizedFunction`   | Обробник зміни ширини колонок       |

### Типовий життєвий цикл

1. Створення масиву даних (`ArrayCreate`).
2. Виклик `_ArrayView_Initialize()`.
3. Створення таблиці через `GenericListCreate()`.
4. Заповнення масиву даними.
5. Знищення масиву при виході зі сторінки.

### Приклад створення списку

```cicode
_ArrayView_Initialize();

GenericListCreate(
    nListAN,
    nListWidth,
    nListHeight,
    nListRowHeight,
    ...
);
```

### Приклад заповнення

У документації наведено приклад формування списку посилань обладнання:

```cicode
EquipRefBrowseOpen(...)
EquipRefBrowseGetField(...)
TagRead(...)
ArraySetString(...)
```

Дані зчитуються з Equipment References і записуються в масив, який відображається в таблиці.

## Generic List Vertical Genie

Genie `genericlist_v` працює аналогічно `genericlist`, але:

- не має заголовка колонок;
- використовує тільки вертикальну прокрутку.

Рекомендований для компактних списків або панелей з обмеженим місцем.

## List Row Genie

Genie `list_row_x<n>` використовується спільно з `alarmlist` або `genericlist` і забезпечує взаємодію з рядками таблиці.

Доступні варіанти:

| Genie          | Максимальна кількість рядків |
| -------------- | ---------------------------- |
| `list_row_x5`  | 5                            |
| `list_row_x10` | 10                           |
| `list_row_x40` | 40                           |
| `list_row_x80` | 80                           |

### Основні параметри

| Параметр            | Призначення                                     |
| ------------------- | ----------------------------------------------- |
| `ArrayAN`           | AN таблиці, до якої прив'язується Genie         |
| `RowOffset`         | Зміщення рядків для другої та наступних таблиць |
| `LeftClickCommand`  | Обробник натискання на рядок                    |
| `RightClickCommand` | Обробник контекстного меню                      |

### Приклад вибору рядка

```cicode
AlarmPage_SelectAlarmRecord(
    DspGetAnFromName("AlarmList")
);
```

### Приклад контекстного меню

```cicode
Alarm_TopAlarmsRow_RightClickCommand(
    DspGetAnFromName("AlarmList")
);
```

## Архітектура роботи

Усі перелічені Genie використовують спільний механізм `ArrayView`.

```text
ArrayCreate()
        ↓
_ArrayView_Initialize()
        ↓
AlarmListCreate()
або
GenericListCreate()
        ↓
ArraySet...
        ↓
Відображення у таблиці
        ↓
ArrayDestroy()
```

Саме тому функції сімейства `ArrayView_*` (зокрема `ArrayView_SetFormat`) використовуються для керування зовнішнім виглядом колонок, форматами відображення та поведінкою таблиць.
