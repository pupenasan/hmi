# Plant SCADA Equipment Properties

Джерело: *Define Equipment in Plant SCADA Studio*

## Загальні властивості

| Поле         | Опис                                                         |
| ------------ | ------------------------------------------------------------ |
| Name         | Ім'я обладнання. Може містити ієрархію через символ `.` (наприклад `Plant1.Filling.Tank1`). Рекомендована довжина до 128 символів, максимальна - 254. |
| Display Name | Людинозрозуміла назва обладнання для відображення під час виконання проєкту. До 254 символів. |
| Cluster Name | Кластер, до якого належить обладнання. Якщо не заданий, обладнання доступне на всіх кластерах. |
| Type         | Тип обладнання. Вибирається з бази Equipment Types.          |
| Location     | Текстовий опис місця розташування обладнання. До 254 символів. |
| Page         | Основна графічна сторінка, пов'язана з обладнанням. Використовується для швидкого переходу оператора до відповідної сторінки. |
| Content      | Перелік пов'язаного контенту через кому: сторінки, фейсплейти, документи тощо. |
| Help         | Контекстна довідка для обладнання. До 254 символів.          |
| Comment      | Довільний коментар. До 254 символів.                         |
| Tag Prefix   | Префікс тегів, пов'язаних з обладнанням. Використовується при генерації та пошуку тегів. |
| I/O Device   | Пристрій вводу-виводу, пов'язаний з обладнанням. Для резервування можна вказати два пристрої через кому. |
| Hidden       | Якщо `TRUE`, обладнання не відображається в дереві Equipment під час виконання. Функціональність при цьому не змінюється. |
| Unique ID    | Унікальний ідентифікатор обладнання (GUID). Генерується автоматично Plant SCADA та доступний лише для читання. |

## Правила для поля Name

### Загальні обмеження

- Імена обладнання повинні бути унікальними в межах кластера.
- Ім'я обладнання не може збігатися з ім'ям Alarm Tag.
- Кореневий елемент ієрархії не може збігатися з назвою кластера.
- Не можна використовувати зарезервовані слова (`IF`, `FOR`, `WHILE`, `END`, `OR`, `AND` тощо).

### Ієрархія

Символ `.` використовується для побудови ієрархії обладнання.

Приклад:

```text
Plant1.Filling.Tank1
```

У цьому прикладі:

```text
Plant1
 └─ Filling
     └─ Tank1
```

Обмеження:

- підтримується до 14 рівнів ієрархії;
- довжина одного сегмента не більше 63 символів;
- сегменти повинні відповідати правилам іменування тегів.

## Властивості безпеки

| Поле | Опис                                                         |
| ---- | ------------------------------------------------------------ |
| Area | Область доступу (Area). Користувач повинен мати доступ до цієї області для виконання операцій з обладнанням. Максимум 16 символів. |

## Користувацькі поля

| Поле                | Опис                                                         |
| ------------------- | ------------------------------------------------------------ |
| Custom1 ... Custom8 | Вісім користувацьких текстових полів для класифікації та фільтрації обладнання через Cicode-функції пошуку. До 254 символів кожне. |

## Властивості планування

| Поле            | Опис                                                         |
| --------------- | ------------------------------------------------------------ |
| Default State   | Стан обладнання за замовчуванням.                            |
| Scheduled       | Вказує, чи бере обладнання участь у плануванні (`TRUE` / `FALSE`). |
| Schedule ID     | Ідентифікатор BACnet-розкладу. Використовується лише при інтеграції з BACnet Schedule. |
| Device Schedule | Якщо `TRUE`, розклад отримується безпосередньо з BACnet-пристрою. |

## Параметри обладнання

| Поле       | Опис                                                         |
| ---------- | ------------------------------------------------------------ |
| Parameters | Значення параметрів обладнання. У Plant SCADA 2023 і новіших версіях використовуються Configuration Parameters замість застарілих Custom Parameters. |

## Примітки щодо Unique ID

Кожне обладнання має GUID такого формату:

```text
XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX
```

Рекомендується дозволяти Plant SCADA автоматично генерувати ці ідентифікатори. Під час компіляції система перевіряє:

- відсутність GUID;
- дублікати GUID;
- некоректний формат GUID.
