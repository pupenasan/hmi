## Додаткові елементи інтерфейсу Situational Awareness

Окрім стандартних сторінок, панелей та віджетів, бібліотеки Situational Awareness містять набір спеціалізованих елементів для побудови навігації, фільтрації, відображення ієрархій та організації робочого простору оператора.

### Tree View

Tree View призначений для відображення ієрархічної структури об'єктів у вигляді дерева. Найчастіше використовується для навігації по моделі обладнання або для фільтрації списків тривог. Кожен вузол дерева може містити прапорець вибору, лічильники активних тривог та відкладених тривог (Shelved Alarms).

Джерелом даних для дерева може бути:

- меню навігації, визначене в Menu Configuration;
- меню, створене динамічно через Cicode;
- модель обладнання проєкту (`__EquipmentModel`).

Для Tree View налаштовуються:

- джерело даних;
- використання відображуваних назв (Display Name);
- пошук через текстове поле;
- розміри дерева;
- відображення прапорців;
- автоматичне встановлення прапорців дочірнім вузлам;
- показ лічильників тривог;
- обробники подій вибору та натискань;
- користувацькі функції завантаження та оновлення даних.

### Фільтри тривог

Для сторінок тривог бібліотека `sa_filter` надає набір готових кнопок фільтрації:

- Acknowledged;
- Unacknowledged;
- Priority;
- State;
- Shelved.

Фільтри розміщуються у верхній частині стандартних сторінок тривог та дозволяють швидко змінювати критерії відображення списку подій. За потреби можна створювати власні фільтри на базі Item Base Genie із використанням довільних Cicode-виразів.

### Панелі вкладок (Tab Bar)

Tab Bar Genie дозволяє створювати набір вкладок, аналогічний Information Zone у стандартному робочому просторі Situational Awareness.

Конфігурація вкладок базується на меню Menu Configuration:

- кожен пункт меню відповідає окремій вкладці;
- для вкладки задається сторінка, яка відкривається після вибору;
- підтримуються значки, закріплення (Pin), приховування кнопок закриття та інші параметри оформлення.

Основні параметри Tab Bar:

- Default Tabs Menu Name;
- Can Tabs be Pinned;
- Max Open Items;
- Tab Bar Width;
- Max Tab Width;
- Allow Duplicate Content.

### Вкладені панелі (Nested Panes)

Situational Awareness підтримує багаторівневу структуру панелей. Сторінка, яка відображається всередині панелі, може містити власні панелі, які своєю чергою можуть завантажувати інші сторінки.

Адресація вкладених панелей виконується через крапкову нотацію:

```text
Pane_A.P1_Content.P2_Left
```

Для сторінок із вкладеними панелями необхідно встановити властивість:

```text
HasPanes = 1
```

що дозволяє Workspace автоматично ініціалізувати та оновлювати вкладені області відображення.

### Спливаючі вікна з панелями

Pop-up вікна можуть містити власну структуру панелей аналогічно звичайним сторінкам. Для їх відкриття використовується функція:

```cicode
WinNewAt(...)
```

Як і для вкладених панелей, сторінка повинна містити параметр:

```text
HasPanes = 1
```

що дозволяє використовувати всередині спливаючого вікна власну систему панелей та механізм Autofill.

### Навігаційні Genie

Бібліотека `sa_navigation` містить готові елементи навігації між сторінками технологічного процесу.

Доступні типи:

| Genie   | Призначення              |
| ------- | ------------------------ |
| link_l  | перехід ліворуч          |
| link_r  | перехід праворуч         |
| link_u  | перехід вгору            |
| link_d  | перехід вниз             |
| slink_l | статичний напис ліворуч  |
| slink_r | статичний напис праворуч |

Посилання задаються шляхом до пункту меню:

```text
Plant1.Area1.MyPage
```

Навігаційні елементи можуть:

- відкривати сторінки іншого розділу;
- вказувати на іншу операторську консоль;
- працювати як Control Links для конкретного обладнання.

### Теми оформлення

Для Workspace доступні готові колірні схеми:

- Blue;
- Grey;
- Green;
- Indigo;
- Orange;
- Dark.

Тема визначає кольори:

- Header Bar;
- Navigation Zone;
- Information Zone;
- кнопок сторінок;
- рамок виділення.

Активна тема задається через Label:

```text
_THEME_Default
```

зі значенням одного з параметрів:

```text
THEME_Blue
THEME_Grey
THEME_SEGreen
THEME_Dark
THEME_Indigo
THEME_Orange
```



### Особливості інтеграції

Для проєктів Situational Awareness також підтримуються:

- використання Scheduler-контролів на майстер-сторінках для прискорення завантаження сторінок планувальника;
- визначення власної дії правої кнопки миші для обладнання через callback `_CALLBACK_EquipmentRightClick`;
- автоматичне оновлення дерев обладнання при зміні моделі обладнання через функцію `_Treeview_MonitorEquipmentModel`.

Таким чином Situational Awareness надає набір готових компонентів для побудови складних операторських інтерфейсів із підтримкою контекстної навігації, вкладених областей відображення, фільтрації тривог та роботи з моделлю обладнання.
