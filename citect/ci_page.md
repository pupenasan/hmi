## PageSetInt

Функція `PageSetInt` пов'язує цілочисельну змінну з певною графічною сторінкою. Такі змінні зберігаються в локальному масиві сторінки і можуть використовуватися як тимчасове сховище даних.

```c
PageSetInt(sLabel, sVar [, iWinNum])
```

- Параметр `sLabel` задає ім'я змінної сторінки, у якій буде збережене значення. 
- Параметр `sVar` містить цілочисельне значення, яке необхідно зберегти.

- Необов'язковий параметр `iWinNum` визначає номер вікна, до сторінки якого належить змінна. Якщо його не вказати, використовується поточне вікно.

Функцію можна використовувати для динамічної зміни параметра `[Page]ScanTime`:

```c
PageSetInt(-2, <scantime>);
```

У багатопроцесному середовищі ця функція не підтримується в серверному процесі. Якщо викликати її із серверного процесу, буде згенерована апаратна тривога.

Функція повертає:

| Значення | Опис                                                       |
| -------- | ---------------------------------------------------------- |
| 0        | Виконано успішно.                                          |
| 269      | Номер вікна (`iWinNum`) не відповідає існуючому вікну.     |
| 274      | Параметр `sLabel` або `sVar` містить недопустиме значення. |

## PageSetStr

Функція `PageSetStr` зберігає рядкову змінну, пов'язану з графічною сторінкою. Такі змінні зберігаються в локальному масиві сторінки і можуть використовуватися як тимчасове сховище даних.

```c
PageSetStr(sLabel, sVar [, iWinNum])
```

- Параметр `sLabel` задає ім'я змінної сторінки, у якій буде збережено рядок.

- Параметр `sVar` містить рядок, який необхідно зберегти. Максимальна довжина рядка становить 128 символів.

- Необов'язковий параметр `iWinNum` визначає номер вікна, до сторінки якого належить змінна. Якщо його не вказати, використовується поточне вікно.

У багатопроцесному середовищі ця функція не підтримується в серверному процесі. Якщо викликати її із серверного процесу, буде згенерована апаратна тривога.

| Значення | Опис                                                       |
| -------- | ---------------------------------------------------------- |
| 0        | Виконано успішно.                                          |
| 269      | Номер вікна (`iWinNum`) не відповідає існуючому вікну.     |
| 274      | Параметр `sLabel` або `sVar` містить недопустиме значення. |

## PageGetInt

Функція `PageGetInt` повертає значення локальної цілочисельної змінної, пов'язаної з графічною сторінкою. Якщо відкрито кілька вікон, кожне з них має власний екземпляр цієї змінної. Такі змінні зручно використовувати в Cicode для зберігання даних, унікальних для кожного вікна.

```c
PageGetInt(sLabel [, iWinNum])
```

- Параметр `sLabel` задає ім'я змінної сторінки, значення якої потрібно отримати.

- Необов'язковий параметр `iWinNum` визначає номер вікна, до сторінки якого належить змінна. Якщо його не вказати, використовується поточне вікно.

- Поточне значення параметра `[Page]ScanTime` можна отримати таким викликом:

```c
PageGetInt(-2)
```

- У багатопроцесному середовищі ця функція не підтримується в серверному процесі. Якщо викликати її із серверного процесу, буде згенерована апаратна тривога.

Функція повертає цілочисельне значення, що зберігається у локальній змінній сторінки з ім'ям `sLabel`.

## PageGetStr

Функція `PageGetStr` повертає значення локальної рядкової змінної, пов'язаної з графічною сторінкою. Такі змінні є локальними для кожної сторінки. Якщо відкрито кілька вікон, кожне з них має власний екземпляр цієї змінної. Це дозволяє зберігати в Cicode рядкові дані, унікальні для кожного вікна.

```c
PageGetStr(sLabel [, iWinNum])
```

- Параметр `sLabel` задає ім'я локальної змінної сторінки, значення якої потрібно отримати.

- Необов'язковий параметр `iWinNum` визначає номер вікна, до сторінки якого належить змінна. Якщо його не вказати, використовується поточне вікно.

- У багатопроцесному середовищі ця функція не підтримується в серверному процесі. Якщо викликати її із серверного процесу, буде згенерована апаратна тривога.

Функція повертає рядкове значення, що зберігається у локальній змінній сторінки з ім'ям `sLabel`.
