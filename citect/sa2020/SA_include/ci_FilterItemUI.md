# FilterItemUI

## Допоміжні функції Filter Item UI

Файл `FilterItemUI.ci` містить допоміжні функції для роботи елементів фільтра з підтримуваним інтерфейсом користувача — Genie з бібліотеки `sa_filter`.

Внутрішні функції:

- `_FilterItemUI_Register`
- `_FilterItemUI_OnClick`
- `_FilterItemUI_IsDisabled`
- `_FilterItemUI_SetState`

Ці функції Cicode передбачають, що об’єкти інтерфейсу Filter Item Genie мають таку структуру:

```text
Group (або Genie)
    будь-який об'єкт (Properties), де зберігаються метадані
    button_base Genie (Base)
        button object (Target)
            rect object (Background)
```

Об’єкт `Properties` містить усі метадані, що стосуються конкретного елемента фільтра. Вони можуть бути безпосередньо пов’язані з властивостями Filter Item:

| Властивість   | Призначення                                                  |
| ------------- | ------------------------------------------------------------ |
| `Filter`      | Фільтр, заданий користувачем.                                |
| `IsExclusion` | Визначає, чи є елемент фільтром виключення. Задається користувачем. |
| `Label`       | Назва елемента фільтра. Задається користувачем.              |
| `Value`       | Значення або умова фільтра. Задається користувачем.          |
| `_FilterItem` | Керується автоматично після прив’язування UI до об’єкта `FilterItem`. |
| `_Init`       | Керується автоматично під час ініціалізації UI.              |

## _FilterItemUI_OnClick

Обробник натискання кнопки фільтра

Функція `_FilterItemUI_OnClick` є обробником `Click Command` для Genie `button_base` і використовується для перемикання критерію фільтрації.

```cicode
FUNCTION _FilterItemUI_OnClick(STRING sFilterExpr, STRING sValueExpr = "")
```

- Коли критерій перемикається в стан ON, функція створює новий елемент фільтра із заданою умовою та прив’язує його до об’єкта фільтра.

- Коли критерій перемикається в стан OFF, раніше прив’язаний елемент видаляється з об’єкта фільтра.

Параметр `sFilterExpr` містить посилання на об’єкт фільтра, у якому зберігається критерій фільтрації. Сюди можна передати як результат виразу, так і безпосередньо задане значення.

Параметр `sValueExpr` задає критерій (значення) фільтра у вигляді результату виразу або безпосередньо заданого значення. За замовчуванням використовується порожній рядок.

Функція не повертає значення (`Nil`).

## _FilterItemUI_SetState

Функція `_FilterItemUI_SetState` встановлює стан графічного елемента, який використовується як кнопка перемикання критерію фільтрації.

```cicode
FUNCTION _FilterItemUI_SetState(INT nPropertiesAn, STRING sValue, STRING pItem = "")
```

Функція викликається як callback при виконанні `FilterItem_CallChanged` для пов’язаного об’єкта Filter Item і оновлює стан кнопки відповідно до поточного стану критерію фільтрації.

У наведеному фрагменті опис параметрів `nPropertiesAn`, `sValue` та `pItem` відсутній.

Функція не повертає значення (`Nil`).
