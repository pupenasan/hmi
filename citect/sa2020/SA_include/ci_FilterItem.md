# FilterItem

## Допоміжні функції Filter Item

Файл `FilterItem.ci` містить допоміжні функції, які представляють окремий критерій фільтрації як елемент (`Filter Item`) усередині об’єкта фільтра.

Доступні такі функції:

| Функція                      | Призначення                                                  |
| ---------------------------- | ------------------------------------------------------------ |
| `FilterItem_Exists`          | Перевіряє існування елемента фільтра.                        |
| `FilterItem_Create`          | Створює елемент фільтра.                                     |
| `FilterItem_Assign`          | Призначає елемент фільтра.                                   |
| `FilterItem_Set`             | Задає параметри елемента фільтра.                            |
| `FilterItem_Destroy`         | Видаляє елемент фільтра.                                     |
| `FilterItem_Equals`          | Порівнює елементи фільтра.                                   |
| `FilterItem_GetProperty`     | Отримує властивість елемента фільтра.                        |
| `FilterItem_SetProperty`     | Задає властивість елемента фільтра.                          |
| `FilterItem_RegisterChanged` | Реєструє функцію, яка викликатиметься при зміні елемента фільтра. |
| `FilterItem_CallChanged`     | Викликає функцію, пов’язану з подією зміни елемента фільтра. |
| `FilterItem_Debug`           | Використовується для діагностики елемента фільтра.           |

Елементи `Filter Item` повинні створюватися в межах об’єкта фільтра.

## FilterItem_GetProperty

Функція `FilterItem_GetProperty` повертає значення властивості елемента фільтра.

```cicode
STRING FUNCTION FilterItem_GetProperty(
    STRING pFilter,
    STRING pItem,
    STRING sProperty
)
```

- Параметр `pFilter` містить посилання на об’єкт фільтра.

- Параметр `pItem` містить посилання на елемент фільтра.

- Параметр `sProperty` задає ім’я властивості, значення якої потрібно отримати. Підтримуються:

  - `Label` — назва елемента фільтра;

  - `Value` — значення (умова) елемента фільтра.

Функція повертає значення заданої властивості у вигляді рядка.

Реалізація функції використовує `MapValueGet()`:

```cicode
RETURN MapValueGet(pFilter, pItem + "." + sProperty);
```

Для перевірки помилок рекомендується викликати `IsError()` до та після виклику функції.
