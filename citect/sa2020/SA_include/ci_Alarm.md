## Alarm_SortList

Застосування сортування до списку тривог. Функція застосовує до переданого списку тривог указаний або стандартний порядок сортування.

Вона перевіряє, чи було сортування фактично застосоване, і лише після цього завершує роботу. Якщо встановити сортування не вдається протягом визначеної кількості спроб, функція записує попередження в журнал і завершується.

```
FUNCTION Alarm_SortList(INT hAn, STRING sOrderByKeys = "", INT bAllowBlocking = FALSE, INT bAllowUserSortOrder = FALSE)
```

Функцію можна викликати з події `On Page Shown`, щоб установити початковий порядок сортування списку тривог.

- Параметр `hAn` задає номер анімації AN, у якому відображається список тривог.

- Параметр `sOrderByKeys` містить рядок ключів сортування, який передається у функцію `AlmSetInfo()`. Якщо цей параметр не заданий, використовується стандартний набір ключів сортування, визначений модульною змінною `l_sOrderByKeys`.

- Параметр `bAllowBlocking` визначає, чи дозволено функції працювати в блокувальному режимі.

- Параметр `bAllowUserSortOrder` визначає, чи може користувач змінювати порядок сортування після застосування стандартного сортування. Якщо користувач видалить усі власні параметри сортування, стандартний порядок буде застосований автоматично знову.

Функція не повертає значення (`Nil`).

Цю функцію слід викликати лише один раз для кожного списку тривог під час входу на сторінку або в події її відображення.
