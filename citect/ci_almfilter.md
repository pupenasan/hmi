# Alarm Filter Functions

Функції роботи з фільтрами тривог/ Наведені нижче функції Cicode призначені для створення, редагування та застосування фільтрів тривог.

| Функція                        | Опис                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| AlarmFilterClose               | Видаляє сеанс фільтрації з пам'яті.                          |
| AlarmFilterEditAppend          | Додає вказаний вираз до поточного сеансу редагування фільтра без перевірки його коректності. |
| AlarmFilterEditAppendEquipment | Додає до поточного сеансу вираз, що містить назви обладнання або категорії, без перевірки його коректності. |
| AlarmFilterEditClose           | Видаляє сеанс редагування фільтра з пам'яті.                 |
| AlarmFilterEditCommit          | Перевіряє сформований фільтр і, якщо він коректний, застосовує його до списку або фільтра, пов'язаного із сеансом. |
| AlarmFilterEditFirst           | Повертає першу частину фільтра.                              |
| AlarmFilterEditLast            | Повертає останню частину фільтра.                            |
| AlarmFilterEditNext            | Повертає наступну частину фільтра.                           |
| AlarmFilterEditOpen            | Створює сеанс редагування для історичного списку, пов'язаного із заданим AN або ім'ям фільтра. |
| AlarmFilterEditPrev            | Повертає попередню частину фільтра.                          |
| AlarmFilterEditSet             | Замінює поточний вміст сеансу редагування заданим виразом без перевірки його коректності. |
| AlarmFilterForm                | Використовується зі старою (Legacy) формою фільтрації. Відображає діалогове вікно для задання критеріїв фільтрації списку тривог або іменованого фільтра. |
| AlarmFilterOpen                | Створює новий іменований фільтр.                             |
| AlarmGetFilterName             | Повертає ім'я фільтра, пов'язаного з указаним AN.            |
| AlarmResetQuery                | Використовується разом із `AlarmFilterForm()`. Очищає фільтр для вказаного джерела фільтрації. |
| LibAlarmFilterForm             | Відображає універсальне спливаюче вікно для налаштування фільтра списку тривог або іменованого фільтра. Доступна лише за наявності проєкту `Lib_controls` у складі основного проєкту. |

> Примітка. Якщо сформований фільтр виявиться занадто складним (наприклад, містить надто багато умов або вкладених дужок), він буде автоматично очищений і не застосовуватиметься. При цьому на клієнті буде згенерована апаратна тривога `Too many alarms in filters`, а в журналі трасування (TraceLog) з'явиться повідомлення про помилку.

## AlarmFilterOpen

Функція `AlarmFilterOpen` відкриває або створює іменований фільтр тривог. Новостворений фільтр спочатку не містить жодних умов і тому відповідає всім тривогам. Докладніше про синтаксис фільтрів див. у розділі «About Named Filters» довідки Plant SCADA.

> Примітка. Якщо сформований фільтр виявиться занадто складним (наприклад, містить надто багато умов або вкладених дужок), він буде автоматично очищений і не застосовуватиметься. При цьому на клієнті буде згенерована апаратна тривога `Too many alarms in filters`, а в журналі трасування (TraceLog) з'явиться повідомлення про помилку.

```cicode
INT AlarmFilterOpen(
    STRING FilterName,
    INT OpenMode
    [, INT AutoCloseMode]
)
```

- Параметр `FilterName` задає ім'я іменованого фільтра.

- Параметр `OpenMode` визначає спосіб відкриття або створення фільтра.

| Значення | Опис                                                         |
| -------- | ------------------------------------------------------------ |
| 0        | Відкрити існуючий фільтр.                                    |
| 1        | Створити новий фільтр.                                       |
| 2        | Відкрити існуючий фільтр, а якщо він не існує — створити новий. |

Необов'язковий параметр `AutoCloseMode` визначає, коли фільтр буде автоматично закритий. Він задається як бітова маска.

| Значення | Опис                                                         |
| -------- | ------------------------------------------------------------ |
| 0        | Фільтр не закривається автоматично. Для його закриття потрібно викликати `AlarmFilterClose()`. |
| 1        | Фільтр автоматично закривається при зміні або закритті сторінки. |

Інші значення зарезервовані.

Функція повертає `0`, якщо фільтр успішно відкрито або створено. У разі помилки повертається код помилки.

Приклад. У наведеному прикладі створюється іменований фільтр `MyFilter`, після чого він закривається.

```cicode
INT nOpenModeOld = 0;
INT nOpenModeNew = 1;
INT nOpenModeAny = 2;

INT nCloseModeManual = 0;
INT nCloseModePageChanged = 1;

INT nError;

nError = AlarmFilterOpen(
    "MyFilter",
    nOpenModeNew,
    nCloseModeManual
);

IF nError = 0 THEN
    nError = AlarmFilterClose("MyFilter");
END
```

## AlarmFilterEditOpen

Функція `AlarmFilterEditOpen` створює сеанс редагування фільтра для історичного списку або списків, пов’язаних із переданим AN, іменованим фільтром або всіма списками тривог на сторінці при використанні значення `-1`.

Сеанс ініціалізується поточним фільтром, який уже застосований до відповідних списків.

Функція повертає дескриптор сеансу, який потім передається в інші функції роботи з фільтром. Якщо переданий AN некоректний або не пов’язаний з історичним списком, функція повертає `-1`.

Функція є блокувальною: виконання задачі Cicode призупиняється до завершення операції.

```cicode
INT AlarmFilterEditOpen(
    STRING FilterName
    або INT AN
    або INT -1
    [, INT AutoCloseMode]
)
```

- Параметр `FilterName` задає ім’я іменованого фільтра.

- Параметр `AN` задає номер анімації списку тривог, наприклад `21` або `11`.

- Значення `-1` означає, що сеанс створюється для всіх списків тривог, які відображаються на сторінці.

- Необов’язковий параметр `AutoCloseMode` визначає режим автоматичного закриття сеансу.

| Значення | Опис                                                         |
| -------- | ------------------------------------------------------------ |
| 0        | Сеанс не закривається автоматично. Для закриття потрібно викликати `AlarmFilterEditClose()`. |
| 1        | Сеанс автоматично закривається при зміні або закритті сторінки. |

Інші значення зарезервовані.

Функція повертає дескриптор сеансу редагування фільтра. У разі помилки повертається `-1`.

Приклад:

```pascal
iHndl = AlarmFilterEditOpen(iAN);
iRet = AlarmFilterEditSet(
    iHndl,
    "Tag=Dig*;Category=1;Area=1;"
);
iRet = AlarmFilterEditAppend(
    iHndl,
    "Priority<20"
);
sRet = AlarmFilterEditFirst(iHndl);
// Tag=Dig*;
sRet = AlarmFilterEditNext(iHndl);
// Category=1;
sRet = AlarmFilterEditLast(iHndl);
// Priority<20;
sRet = AlarmFilterEditPrev(iHndl);
// Area=1;
iRet = AlarmFilterEditClose(iHndl);
```

У цьому прикладі відкривається сеанс для списку з AN `iAN`, задається початковий фільтр, до нього додається ще одна умова, після чого окремі частини фільтра переглядаються функціями `First`, `Next`, `Last` і `Prev`. Наприкінці сеанс закривається.

## AlarmFilterEditCommit

Функція `AlarmFilterEditCommit` приймає дескриптор сеансу редагування фільтра, перевіряє сформований у цьому сеансі фільтр і, якщо він коректний, застосовує його до списку, пов’язаного із сеансом. Функція є блокувальною: виконання задачі Cicode призупиняється до завершення операції.

```cicode
INT AlarmFilterEditCommit(INT hSession)
```

Параметр `hSession` — дескриптор сеансу для історичного списку, попередньо отриманий функцією `AlarmFilterEditOpen()`.

Функція повертає `0`, якщо сеанс фільтра існує і операція виконана успішно. В іншому випадку повертається код помилки.

Приклад:

```cicode
INT nError;
nError = AlarmFilterEditSet(
    hEdit,
    "tag=Dig*;Category=1;"
);
nError = AlarmFilterEditCommit(hEdit);
```

У цьому прикладі спочатку задається фільтр за тегами `Dig*` і категорією `1`, після чого `AlarmFilterEditCommit()` перевіряє та застосовує сформований фільтр.
